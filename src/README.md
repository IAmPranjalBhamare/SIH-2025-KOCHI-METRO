# 🚇 Kochi Metro Fleet Management System

An AI-driven decision support platform for Kochi Metro's fleet management operations, featuring Kerala cultural theming and comprehensive fleet optimization capabilities.

## 🌟 Features

### 🔐 Authentication System
- **Enhanced Login Pages**: Role-based authentication with Kerala cultural theming
- **Admin Dashboard**: Complete fleet oversight and Train Induction List management
- **Worker Dashboards**: Six specialized categories for different operational roles

### 🚆 Fleet Management
- **Train Induction List**: Comprehensive fleet tracking with download capabilities (PDF, Word, Excel)
- **Decision Support System**: AI-powered recommendations for fleet deployment
- **Real-time Fleet Positioning**: 3D visualization of train locations
- **Maintenance Scheduling**: Predictive maintenance with AI insights

### 🎯 Specialized Dashboards
1. **Fitness Certificates Dashboard** - Certificate management and compliance
2. **Job Cards Dashboard** - Work order tracking and management
3. **Branding Dashboard** - Advertisement and branding coordination
4. **Mileage Balancing Dashboard** - Fleet utilization optimization
5. **Cleaning & Detailing Dashboard** - Maintenance and cleaning schedules
6. **Stabling Geometry Dashboard** - Depot and stabling management

### 🚀 AI-Powered Features
- **Predictive Maintenance AI**: Proactive maintenance scheduling
- **Voice Command Center**: Voice-controlled fleet operations
- **Gamification System**: Performance tracking and incentives
- **Real-time Analytics**: Comprehensive reporting and insights

### 🎨 Kerala Cultural Theming
- **Backwaters Imagery**: Beautiful Kerala landscape backgrounds
- **Malayalam Text Support**: Bilingual interface (English/Malayalam)
- **Kerala Color Palette**: Green and blue themes inspired by Kerala's nature
- **Cultural Elements**: Palm trees, boats, and traditional Kerala motifs

## 🛠️ Technology Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS v4.0
- **Animations**: Motion (Framer Motion)
- **Charts**: Recharts
- **UI Components**: Radix UI + Custom ShadCN components
- **Icons**: Lucide React
- **Forms**: React Hook Form
- **Notifications**: Sonner

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd kochi-metro-fleet-management
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
# or
yarn build
```

## 🎮 Usage

### For Administrators
1. **Login**: Use admin credentials to access the administrative dashboard
2. **Fleet Overview**: Monitor all 25 trainsets and their current status
3. **Train Induction List**: Generate and download comprehensive fleet reports
4. **Decision Support**: Get AI-powered recommendations for fleet deployment

### For Workers
1. **Category Selection**: Choose from six specialized work categories
2. **Task Management**: View and manage assigned tasks with priority sorting
3. **Analytics**: Access relevant charts and performance metrics
4. **Voice Commands**: Use voice interface for hands-free operations

## 🔧 Configuration

### Environment Variables
Create a `.env.local` file in the root directory:

```env
# Add your environment variables here
VITE_APP_TITLE="Kochi Metro Fleet Management"
VITE_API_URL="http://localhost:3001"
```

### Customization
- **Colors**: Modify `styles/globals.css` for theme customization
- **Components**: Add new components in the `components/` directory
- **Features**: Extend functionality in `components/unique-features/`
